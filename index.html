📷 프라이빗 미디어 공간

💡 미디어 업로드 및 공유 가이드

🎥 유튜브 영상 올리는 법 (일부 공개)

1. 유튜브 하단의 [+] 버튼을 눌러 영상을 업로드합니다.

유튜브 앱 하단 중앙의 플러스 버튼을 눌러 영상을 선택하고 업로드를 진행합니다.

2. 세부정보 화면에서 공개 상태를 [일부 공개]로 설정합니다.

공개 상태 메뉴에 들어가서 '일부 공개'를 선택하여 링크가 있는 사람만 볼 수 있게 설정합니다.

3. 업로드된 영상의 [공유] > [링크 복사]를 진행합니다.

재생 화면에서 공유 버튼을 누르고 링크 복사를 선택한 뒤 웹사이트에 붙여넣습니다.

🖼️ Imgur 사진 올리는 법 (숨김 / 직접 링크 복사)

1. 카카오톡 등에서 링크를 엽니다.

메시지 앱이나 카카오톡 링크 화면입니다.

2. 하단 메뉴 버튼을 누릅니다.

하단 메뉴 바의 점 3개 버튼을 누릅니다.

3. [다른 브라우저로 열기]를 선택합니다.

메뉴에서 [다른 브라우저로 열기]를 선택합니다.

4. 삼성 브라우저 화면이 열립니다.

브라우저 창이 정상적으로 열린 모습입니다.

5. 브라우저 메뉴에서 [데스크톱 사이트]를 체크합니다.

브라우저 설정 메뉴에서 [데스크톱 사이트]를 활성화합니다.

6. Imgur에 접속하여 구글 계정으로 로그인합니다.

우측 상단 버튼을 눌러 구글 계정으로 로그인합니다.

7. 로그인 완료 후 업로드 페이지로 이동합니다.

로그인 완료 후 상단의 업로드 메뉴를 누릅니다.

8. [Choose Photo/Video] 버튼을 누릅니다.

사진/동영상 선택 버튼을 터치합니다.

9. 작업 선택에서 [파일]을 선택합니다.

파일 앱을 통해 사진을 가져옵니다.

10. [갤러리] 등에서 업로드할 사진을 선택합니다.

사진이 있는 갤러리/이미지함을 엽니다.

11. 비공개 설정은 그대로 가만히 두면 됩니다.

별도의 비공개 설정 조작 없이 그대로 둡니다.

12. 사진을 꾹 누르고 [이미지 보기]를 선택합니다.

사진을 손가락으로 꾹 눌러 [이미지 보기]를 누릅니다.

13. 주소를 복사합니다.

이미지 링크 주소(.jpg 등)를 복사합니다.

14. 웹사이트에 링크를 붙여넣고 등록합니다.

제목 입력 후 등록하기를 눌러 완료합니다.
